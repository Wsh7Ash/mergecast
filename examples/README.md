# Example scenario

The demo repository is generated by `scripts/demo.py` rather than committed,
so the example cannot drift from the code. It builds this shape:

```text
base (60-line src/app.py)
├─ main
│  ├─ src/app.py       lines 11-13 replaced (charge_v3), lines 49-52 replaced
│  ├─ src/config.py    line 4 replaced (TIMEOUT)
│  └─ docs/legacy.md   deleted
└─ feature/payments
   ├─ src/app.py       lines 11-13 replaced (charge_v2), line 49-50 replaced
   ├─ src/config.py    line 30 inserted (RETRY_LIMIT)
   └─ docs/legacy.md → docs/payments.md (rename)
```

Expected verdicts:

| File | Level | Why |
|---|---|---|
| `src/app.py` | conflict | both sides rewrote lines 11-13 and the 49-52 region |
| `docs/legacy.md` | conflict | delete on `main`, rename on the feature branch |
| `src/config.py` | touch | edits at lines 4 and 30 |

Run `python scripts/demo.py` to reproduce it; the captured output is in
`results/`.
